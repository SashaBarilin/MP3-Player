Project Title: Native Android MP3 Player

Subtitle / Role: Pet Project | Java, Android Studio, Android SDK

Links: https://drive.google.com/drive/folders/1-dgsmkEaQxVeW5_uNSzxnkxcSJrDZ8Cg?usp=drive_link

Description:

Developed a fully functional Android audio player application capable of scanning, managing, and playing local MP3 files.

Implemented local device storage querying (MediaStore API) to efficiently load and render massive music libraries, handling over 5,000+ audio tracks smoothly.

Built a user-friendly interface featuring dynamic playback controls, real-time progress tracking (SeekBar), and an optimized scrollable tracklist using RecyclerView.

Integrated Android's core MediaPlayer API for robust audio playback logic, including play, pause, track skipping, and seek functionalities.
